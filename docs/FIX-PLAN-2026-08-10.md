   This makes the two trees unable to drift silently again.

**Acceptance:** parity test green across all 5 repos; factory suite still 115+ passing.

### 1.2 Daily launchd gate leaves evidence uncommitted — make it self-committing

**Symptom:** `com.blackswanlabz.msb-factory-gate` runs `scripts/factory_gate_daily.sh`
daily at 06:15 CDT. It regenerates evidence but **never commits it** — every daily run
leaves the tree dirty, and a transient flake (like today's r01 `pytest exit 2`) leaves
FAILED evidence sitting uncommitted, flipping the ledger to FAILING until a human re-gates.
Today that flake cost a manual intervention.

**Do (in `/Users/lordwilson/msb-v3/scripts/factory_gate_daily.sh`):**
1. After the gate run, on **PASS**: `git add artifacts/hygiene/ && git commit -m 'chore: daily gate evidence (PASS) <date>' && git push origin HEAD` (evidence-only; the script already knows REPO).
2. On **FAIL**: keep the alert (already there) but ALSO leave the FAILED evidence committed
   locally (do NOT push) so the ledger's REGRESSED/CONTESTED machinery has the truth without
   polluting CI. Record the verdict + alert-sent in a small JSON event log
   (`artifacts/hygiene/daily_gate_events.jsonl`, append-only).
3. Guard: only commit if `git status --porcelain -- artifacts/hygiene/` is non-empty (idempotent).
4. Update the launchd plist comment if behavior changes materially.

**Acceptance:** two consecutive manual runs of the daily script leave the msb-v3 tree clean
when PASS; a forced FAIL run leaves committed FAILED evidence + an alert + a logged event.
